Everyone holds the lock

Logic that belongs together is spread over every call site. And the state cannot react to anything: it changes only when someone locks it.

// api.rs
let mut account = state.lock().await;
account.balance -= amount;
// interest.rs
let mut account = state.lock().await;
account.balance += account.balance / 100;
// alerts.rs: who checks for a negative balance, and when?
let account = state.lock().await;
if account.balance < 0 { notify().await; }
